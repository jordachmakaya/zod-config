# Support

## Where to ask

- Use GitHub issues for reproducible bugs.
- Use feature requests for proposed API or behavior changes.
- Use GitHub Discussions if they are enabled later.

## Before opening an issue

Please include:

- Package version.
- Node.js version.
- Package manager and version.
- Framework details if using NestJS.
- Minimal schema/config example.
- Error output with secrets removed.

## Security issues

Security issues are handled separately. Do not open a public issue for
vulnerabilities or secret leaks. See `SECURITY.md`.

## Private support

This project does not provide a private support guarantee. Maintainers respond
when time and project scope allow.
